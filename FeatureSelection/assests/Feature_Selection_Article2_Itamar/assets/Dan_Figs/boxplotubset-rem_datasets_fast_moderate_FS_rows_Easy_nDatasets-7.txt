On-figure title: Easy (7 datasets)

This plot shows the distribution of mean cross-validated AUC. For FS buckets: one value per feature-selection run in each FS bucket column. The No-FS column is the baseline with mean of mean CV AUC if duplicate No-FS rows exist for that dataset. Datasets are restricted to the Remainder subset (FS runs exist only in fast and moderate buckets in this benchmark). FS columns: fast / moderate; then No-FS. No stratification by supervision, adoption type, or algorithm family. The horizontal line inside each box is the median; the box spans the interquartile range (IQR); points beyond the whiskers are fliers.

Medians and sample sizes (n = number of mean CV AUC values in that box):
  - fast: median (mean CV AUC) = 0.844000, n=912
  - moderate: median (mean CV AUC) = 0.764000, n=143
  - No FS: median (mean CV AUC) = 0.936000, n=7

Whiskers (percentiles): Matplotlib default boxplot whiskers are **not** fixed percentiles. With whis=1.5 (Tukey's rule), each whisker extends to the most extreme data point that still lies inside [Q1 - 1.5*IQR, Q3 + 1.5*IQR], where Q1/Q3 are the 25th/75th percentiles and IQR = Q3 - Q1. This script uses whis=1.5, matching the figure.
