On-figure title: Easy (45 datasets)

This plot shows the distribution of mean cross-validated AUC. For FS buckets: one value per feature-selection run in each FS bucket column. The No-FS column is the baseline with mean of mean CV AUC if duplicate No-FS rows exist for that dataset. Datasets are restricted to the Core subset (each has FS runs in all three runtime buckets). FS columns: fast / moderate / slow; then No-FS. No stratification by supervision, adoption type, or algorithm family. The horizontal line inside each box is the median; the box spans the interquartile range (IQR); points beyond the whiskers are fliers.

Medians and sample sizes (n = number of mean CV AUC values in that box):
  - fast: median (mean CV AUC) = 0.919000, n=4822
  - moderate: median (mean CV AUC) = 0.905000, n=2191
  - slow: median (mean CV AUC) = 0.872000, n=556
  - No FS: median (mean CV AUC) = 0.988500, n=45

Whiskers (percentiles): Matplotlib default boxplot whiskers are **not** fixed percentiles. With whis=1.5 (Tukey's rule), each whisker extends to the most extreme data point that still lies inside [Q1 - 1.5*IQR, Q3 + 1.5*IQR], where Q1/Q3 are the 25th/75th percentiles and IQR = Q3 - Q1. This script uses whis=1.5, matching the figure.
